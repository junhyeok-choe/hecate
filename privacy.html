Data practices · Updated 2026-10-24

Privacy policy

This policy describes the current personal Google Drive integration configured with rclone and the informational Hecate website. It does not cover hypothetical future services.

Google account access

The operator may authorize a local rclone application to access Google Drive. Depending on the OAuth scopes actually granted, rclone can list files and metadata, download content, create and upload content, rename or move files, and delete files. Full Drive access is not restricted to a single folder by the rclone root_folder_id setting.

Purpose and use

Drive access is used for personal file management and mounting through rclone at the direction of the account holder. It is not used to sell personal information, target advertising, or train AI models as part of this website.

Storage and transfers

With this configuration, Google OAuth tokens are retained in the operator's local rclone configuration. Files and cache data may be kept on the operator's device according to rclone settings. rclone communicates with Google APIs to carry out file operations. The Hecate website neither receives tokens nor processes Google Drive file contents.

Third-party hosting

This informational website is hosted on GitHub Pages. GitHub may process ordinary website request information under its own policies. This site does not contain forms, analytics scripts, or Drive API client-side requests.

Control and revocation

Account holders can revoke access from their Google Account connections settings. Local OAuth tokens and cached content are managed through the local rclone configuration and cache settings. Revoking Google access does not itself delete local copies.

Changes and contact

The documentation will need to be revised before expanding data processing to a hosted service, AI agent, MCP connector, or additional users. Project information and its maintainer are available on GitHub.
